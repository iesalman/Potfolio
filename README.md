# Eyad Seleman — Full-Stack MEAN Stack Developer Portfolio

A clean, production-grade **HTML5, CSS3, and Vanilla JavaScript** portfolio for **Eyad Seleman**, featuring real MEAN Stack and web engineering projects and ready for direct hosting on **GitHub Pages**.

## Featured & Engineering Projects
1. **Nawa Market** — Bilingual (Arabic/English RTL/LTR) Full-Stack E-Commerce Storefront & Manager Dashboard (`Angular 21`, `Node.js`, `Express 5`, `MongoDB`, `JWT`, `Multer`)
2. **Simple Shop Management System** — Role-Based Retail Inventory, Orders & KPI Reports Portal (`Node.js`, `Express 5`, `MongoDB`, `Mongoose`, `EJS`, `Bootstrap 5`, `JWT`)
3. **Pato Place Restaurant** — Multi-Page Responsive Hospitality Website (`HTML5`, `CSS3`, `JavaScript`, `Bootstrap`)
4. **Hotel Management Dashboard API** — 100-Room RESTful Backend with Per-Room Mutex Concurrency Locks & E2E Tests (`Node.js`, `Express 5`, `MongoDB`, `Joi`)
5. **Movies Discovery & CRUD Platform** — Genre-Filtered Cinema Catalog & Multer Upload System (`Node.js`, `Express 5`, `MongoDB`, `EJS`, `Multer`)
